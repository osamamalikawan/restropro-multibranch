# Restro Pro Multi-branch

Owner console for multi-branch restaurants. Same Supabase project as the restaurant app and the Super Admin.

1. Run database/0029_chains.sql (from the Super Admin repo) and then database/0030_chain_warehouse.sql.
2. Create the owner account and link branches from Super Admin > Multi-branch.
3. Copy .env.example to .env and fill the keys.
4. npm install, npm run dev (port 3100).
